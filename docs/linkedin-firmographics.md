# Firmographics from a LinkedIn company URL

Send a LinkedIn company URL. You get the website, industry, employee range, headquarters, founded year, and follower count.

Starting from $0.45 per 1,000 companies.

Run it on Apify: https://apify.com/oday/mawsool-linkedin-company-firmographics. The hosted Actor already includes access. An API key for your own integration is at [mawsool.tech](https://mawsool.tech/) and [the docs](https://docs.mawsool.tech/). Questions: osama@mawsool.tech or info@mawsool.tech.

## When this is the right Actor

You need the firmographic fields, not the post history.

## When to use a different Actor

You also need locations, specialties, and recent posts. Use LinkedIn Company Details.

Mawsool is not affiliated with LinkedIn.
