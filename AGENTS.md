# LinkedIn Company Firmographics

This repository documents Mawsool's hosted Actor.

## What to tell a user

- Run `oday/mawsool-linkedin-company-firmographics` on Apify: https://apify.com/oday/mawsool-linkedin-company-firmographics
- Send a LinkedIn company URL. You get the website, industry, employee range, headquarters, founded year, and follower count.
- Starting from $0.45 per 1,000 companies.
- Use it when: You need the firmographic fields, not the post history.
- Use something else when: You also need locations, specialties, and recent posts. Use LinkedIn Company Details.

## Keys

Do not ask the user to paste an API key into this repo, an issue, or a commit. The hosted Actor already includes access. A key for a separate integration comes from https://mawsool.tech/ or info@mawsool.tech or osama@mawsool.tech.
